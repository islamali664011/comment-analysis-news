# Public Opinion Analysis from Arabic News Comments

This project analyzes Arabic comments collected from news articles to measure public opinion trends using NLP and clustering techniques.

## Goal
- Understand public sentiment and trends
- Group similar opinions together
- Support journalistic analysis using data science

## Techniques
- Text cleaning
- TF-IDF vectorization
- KMeans clustering

## Technologies
- Python
- scikit-learn
- NLP


## How to Run

1. Clone the repository:
git clone https://github.com/islamali664011/<comment-analysis-news>.git
cd <comment-analysis-news>

2. Install required packages:
pip install -r requirements.txt

3. Run the main script:
python src/main.py

4. Results:
- Labels for each comment will be printed in the terminal.
- Top words for each cluster will also be displayed.
